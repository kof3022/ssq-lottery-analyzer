# 双色球走势分析工具

基于中国福彩官网公开开奖数据，按红球三区（1-11 / 12-22 / 23-33）与蓝球（1-16）做**频率、遗漏、马尔可夫链、决策树与随机森林**分析的本地小工具，提供极简网页操作界面。

> 声明：开奖结果独立随机，本工具仅做历史数据统计展示，不构成任何投注建议，请理性购彩。

## 功能特性

- **本地网页界面**：极简风格，双击启动，浏览器自动打开，无需安装任何第三方依赖
- **一键刷新数据**：从福彩官网公开接口拉取最新开奖，自动更新本地数据
- **指定期分析**：输入任意期号（已开奖或下一期），自动取该期之前的 **528 期**做第一轮分析
- **双轮分析**：第二轮结合最近 **16 期**数据，给出"前528期 + 近16期加权"的综合推荐一注
- **多方法推荐**：分区频率与遗漏推荐、马尔可夫转移概率（见分析报告脚本）、决策树 + 随机森林模型预测（纯 Python 自实现，零依赖）
- **过去期验证**：分析过去的期数时，会同时显示实际开奖号码供对比

## 快速开始

### Windows

1. 双击 `启动双色球工具.bat`
2. 浏览器自动打开 `http://127.0.0.1:8765`（若端口被占用会自动改用其他端口）

### 命令行

```bash
python server.py
```

要求：Python 3.8+，仅使用标准库，无需 pip 安装任何包。

## 使用说明

1. **刷新数据**：点击「刷新最新数据」，工具会从福彩官网公开接口拉取最新开奖并更新本地数据
2. **分析指定期**：输入期号（如 `2026091`，或过去任意期如 `2026085`），点击「开始分析」
3. **快捷分析**：点击「快捷：分析下一期」自动分析最新一期的下一期
4. **查看结果**：
   - 综合推荐一注（前528期 + 近16期加权）
   - 第一轮（前528期）与第二轮（近16期）的推荐对比
   - 机器学习推荐（决策树 / 随机森林 / 融合一注，含概率）
   - 频率明细（前528期与近16期各区号码的频率、当前/平均/最大遗漏）

## 分析方法

- **分区**：红球一区 1–11、二区 12–22、三区 23–33；蓝球 1–16
- **频率分析**：统计各分区出号个数与号码出现占比，识别热/冷
- **遗漏分析**：统计号码与分区状态的当前遗漏、平均遗漏、最大遗漏
- **马尔可夫链**（`analysis.py`）：将分区组合 / 蓝球号码视为一阶马尔可夫过程，用历史转移对估计转移概率矩阵（拉普拉斯平滑）
- **决策树 / 随机森林**（`ml_model.py`）：将"号码 n 在下一期是否开出"建模为二分类，特征仅使用目标期之前的历史数据（近 1/3/5/10/20/50 期出现次数、遗漏、分区等），逐号码输出下期开出概率

## 数据来源与安全

- 数据来源：中国福彩官网公开开奖数据接口（`cwl.gov.cn`），**公开接口、无鉴权、无 API Key**
- 本地数据保存在 `双色球开奖数据_全量历史.csv`，未提交任何密钥或账号信息
- 涉及网络请求仅用于拉取开奖数据，数据与代码均在本机运行
